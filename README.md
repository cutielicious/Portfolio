\# Khuthadzo Mudau - Virtual CV \& Developer Portfolio



Welcome to the official source code repository for my personal developer portfolio and virtual CV. This project showcases my academic achievements, technical proficiencies, enterprise software projects, and community involvement as a final-year Information Technology student at North-West University (NWU).



\---



\## Built With



\- \*\*HTML5 \& CSS3:\*\* Semantic markup, CSS Custom Properties (Variables), Flexbox, CSS Grid.

\- \*\*JavaScript (ES6+):\*\* DOM manipulation, smooth scroll handling, light/dark theme persistence via LocalStorage.

\- \*\*Custom Interactive Features:\*\*

&#x20; - Dual-ring custom cursor mechanics with dynamic scaling and color-morphing state reactions.

&#x20; - Infinite horizontal scrolling \*\*Tech Stack Ticker\*\* with CSS keyframe animation.

&#x20; - Scroll-reveal card visibility animations.



\---



\## Key Website Features



1\. \*\*Light \& Dark Mode Switcher:\*\* Seamlessly toggles theme color matrices and preserves user selection across sessions using browser localStorage.

2\. \*\*Interactive Custom Cursor:\*\* Custom outer ring with elastic tracking and a sharp, neon-pink center dot.

3\. \*\*Infinite Tech Ticker:\*\* Displays core technologies (Java, C#, C++, Python, JavaScript, SQL, .NET MAUI) in a continuous sliding loop.

4\. \*\*Responsive Layout:\*\* Fully compatible across all viewports (Mobile, Tablet, Desktop) and modern web browsers.
